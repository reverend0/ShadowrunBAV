# ShadowrunBAV

A vehicle and drone builder for Shadowrun Sixth World, by the design rules of *Double Clutch*. Rust core, TypeScript UI, Tauri shell.

The owner is learning Rust through this project: write idiomatic, readable Rust, and explain non-obvious Rust (ownership, lifetimes, traits, error handling) in comments or replies.

The owner keeps a copy of the book outside the repository; never commit it or its text. Where the book contradicts itself, ask the owner and record the ruling in RULINGS.md (numbered, with a test).
